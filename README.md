Superstore Performance Analysis Dashboard (Power BI)

## Project Overview
This project analyses retail sales data using Power BI to provide insights into sales performance, profit, customer behaviour.

## Dataset
- Superstore Dataset
- Tables used: Orders, Customers, Products, Transaction, Geography, Date

## Data Modelling
- Star schema with Transaction as the fact table
- One-to-many relationships with dimension tables

## Key KPIs
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Total Quantity

## Tools & Skills
- Power BI Desktop
- Power Query
- DAX
- Data Modelling
- Data Visualisation

## Key Insights
- Technology category generates the highest sales.
- Certain sub-categories operate at a loss despite high sales.
- Corporate segment has higher average order value.
- Sales peak during year-end months.
